# SYNONYM Brand Tokens

Read \`docs/brand/SYNONYM-BRAND-TOKENS.md\`, \`docs/brand/SYNONYM-DESIGN-GUIDELINES.md\`, and \`src/app/redesign-preview/brand-v05.css\`.

**Brandbook is authority**, seven-page PDF «Краткая информация по логотипу Синоним»: green \`#73A341\`, terracotta \`#D47750\`, sand \`#E8D9B5\` (page 3); logo olive \`#4A5335\` and terracotta \`#C96A4A\` (page 5); Playfair Display headings and Inter interface (page 4).

Never recreate the logo in text, reshape or recolor it, crop, rotate, add shadows, strokes or gradients. Keep >=80px visible screen width and clear space at least the logo letter O height.

**Derived UI:** accessible CTA white-on-dark-olive (8.14:1), avoid small white text on bright green or terracotta. Scope changes to \`/redesign-preview\`. Run \`npm run brand:check\`.
