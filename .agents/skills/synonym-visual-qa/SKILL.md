# SYNONYM Visual QA

Read \`docs/brand/SYNONYM-VISUAL-QA.md\`. Run \`npm run brand:check\`, \`npm run media:check\`, TypeScript, ESLint, production build and Playwright visual QA.

Confirm computed CSS colors, Playfair Display/Inter, header/footer authentic original logos and >=80px visible width, primary button contrast and six-block home ordering. Compare full-page screenshots on desktop and mobile; inspect video/hero, category filters, PDP variants and dialogs.

Treat green CI as functional regression coverage, **not** full editorial art approval. Test catalog merchandising with real AdvantShop only in an authorized credential-protected test environment. Keep QA demo non-purchasable. Report unresolved visual issues explicitly.
